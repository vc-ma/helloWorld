# 扫雷游戏 (Minesweeper)

一个现代化的网页版扫雷游戏，使用纯HTML、CSS和JavaScript开发。

## 功能特性

- 🚩 经典扫雷游戏玩法
- 🎮 三种难度等级：简单、中等、困难
- ⏱️ 计时器功能
- 🏁 雷数计数器
- 💣 右键标记地雷
- ❓ 右键问号标记
- 🎉 胜负判定和动画效果
- 📱 响应式设计，支持移动设备

## 游戏规则

1. **开始游戏**：点击任意格子开始游戏
2. **揭示格子**：左键点击格子来揭示其内容
3. **标记地雷**：右键点击格子可以：
   - 第一次右键：标记为地雷 🚩
   - 第二次右键：标记为疑问 ❓
   - 第三次右键：取消标记
4. **数字含义**：揭示的数字表示周围8个格子中地雷的数量
5. **胜利条件**：揭示所有非地雷格子
6. **失败条件**：点到地雷

## 难度等级

| 难度 | 网格大小 | 地雷数量 |
|------|----------|----------|
| 简单 | 9×9      | 10       |
| 中等 | 16×16    | 40       |
| 困难 | 30×16    | 99       |

## 如何运行

1. 下载所有文件到本地目录
2. 用浏览器打开 `index.html` 文件
3. 或者启动本地服务器：
   ```bash
   python3 -m http.server 8000
   ```
   然后访问 `http://localhost:8000`

## 技术实现

- **HTML5**: 页面结构
- **CSS3**: 样式和动画效果
- **JavaScript ES6+**: 游戏逻辑和交互
- **响应式设计**: 适配不同屏幕尺寸
